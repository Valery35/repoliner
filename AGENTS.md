# AGENTS.md - рабочий контекст Repoliner

Этот файл читается первым в начале любого нового чата. Единственный
источник правды - этот репозиторий, а не переписка. Если что-то
изменилось в коде или процессе, правка идёт сюда.

## Что это

Модуль QGIS Repoliner. Он собирает репозиторий модулей QGIS
(`plugins.xml`) из готовых zip-архивов модулей и держит набор таких
репозиториев. Разработка ООО «Информ++», Пермь. Код пишет Claude,
Валерий ставит задачи, проверяет на живых данных и принимает решения.

Модуль отделён от Isoliner (сентябрь 2026). Задача возникла из ночного
канала Isoliner (`nightly/plugins.xml` в репозитории Isoliner), но в
Isoliner ничего из этого модуля не входит, и зависимости от него нет.

Совместимость QGIS 3.16 - 4.99, Qt5 и Qt6. Чистый Python, без
сторонних библиотек. Версия и changelog - в `repoliner/metadata.txt`.

## Решения Валерия (сентябрь 2026)

- **Репозиторий** `https://github.com/Valery35/repoliner`, туда же
  ведут `homepage` и `tracker` (`/issues`). Первая выкладка в каталог -
  0.1.4, без пометки «экспериментальный».
- **Окно на панели**, а не инструмент Processing. Дерево «реестр -
  модули» с отметками.
- **Список реестров хранится в настройках QGIS**, ключ
  `Repoliner/repositories`, пути по одному в строке. Сам реестр описан
  своим `plugins.xml` и больше нигде.
- **Архивы не копируются.** Архивы готовятся заранее, `download_url`
  ведёт на место архива (`file:///`). Перенос архива ломает установку,
  поэтому окно показывает состояние архива у каждого модуля.
- **Архив выбирает пользователь, с любым именем файла.** Repoliner
  архив не отбрасывает, а имя модуля в реестре берёт по папке внутри
  архива (0.1.1).
- **Реестр подключается в QGIS кнопкой** (0.1.2). Пишется в
  `app/plugin_repositories/<имя>/url` и `enabled`, затем зовётся
  `pyplugin_installer.instance().reloadAndExportData()`. Повод - на живом
  прогоне в поле адреса был вставлен путь к папке, и QGIS ответил
  «Неизвестный протокол «c»». Официальный репозиторий окно не
  отключает, это решение администратора машины.
- **Адрес сервера** (0.1.2) хранится атрибутом `base_url` на корне
  `plugins.xml`, QGIS его не читает. Адрес архива - адрес сервера плюс
  путь от папки реестра. Архив вне папки реестра при заданном адресе
  не принимается, смена адреса откатывается целиком.
- **Открываются только свои реестры**, с меткой
  `<plugins generator="Repoliner">`. Чужой файл, включая официальный
  каталог, не читается. В ядре есть `own_only=False`, из окна он не
  вызывается.

## Как QGIS читает реестр (проверено по исходникам 3.40 и master)

`python/pyplugin_installer/installer_data.py`, `xmlDownloaded`.

- Модуль определяется **именем до первой точки** из `file_name`, а без
  него из `download_url`.
- После скачивания установщик (`qgsplugininstallerinstallingdialog.py`,
  `requestFinished`) копирует из архива **только папку с этим именем**.
  Нет такой папки - «Could not store plugin to the plugin directory».
  Поэтому `file_name` пишется как «папка модуля в архиве».zip, а
  `download_url` ведёт на файл с любым именем. Поймано на 0.1.0 живым
  прогоном: `topoliner_upload.zip` с папкой `topoliner` не ставился.
  Следствие для Isoliner: ночная сборка с папкой `grid_isolines` в
  реестре неизбежно называется `grid_isolines` и сливается с каталогом.
- Совпадение имён в двух репозиториях сливает записи в одну. Окно
  предупреждает о совпадении между своими реестрами.
- `download_url` берётся **как есть** и относительно адреса реестра
  **не разрешается** (так делается только для `icon` и только для
  http). Отсюда полные адреса.
- Сетевая папка Windows: `\\сервер\папка\x.zip` пишется как
  `file://сервер/папка/x.zip`. Проверено на QGIS 4.0.3 через
  административный ресурс `\\127.0.0.1\C$`: реестр и архив читаются.
  `file://localhost/...` Qt считает локальным диском и не открывает,
  поэтому `localhost` заменяется на `127.0.0.1`.
- http проверен на QGIS 4.0.3 временным сервером на 127.0.0.1: реестр с
  `?qgis=4.0` и архивы 1,2 и 5,6 МБ скачиваются, отсутствующий архив
  даёт ContentNotFoundError. Полная установка из http-реестра на живой
  машине не прогонялась.
- Модули из других репозиториев окно берёт из того, что менеджер
  модулей уже загрузил (`installer_data.plugins.repoCache`), сеть не
  трогает. До первого открытия менеджера предупреждений нет.
- К адресу реестра QGIS дописывает `?qgis=X.Y`. Для `file:///` это не
  мешает: проверено на QGIS 4.0.3, как и скачивание zip по `file:///` с
  пробелом в пути.
- Модуль вне диапазона `qgis_minimum_version` - `qgis_maximum_version`
  в списке не показывается вовсе. Пустой максимум считается как
  «старшая цифра минимума».99. Окно пишет «QGIS X модуль не покажет».

Таблица соответствия полей `metadata.txt` и `plugins.xml` - в шапке
`repoliner/core.py`, там же список непереносимых полей.

## Карта модулей (repoliner/)

| Файл | Роль |
|---|---|
| `__init__.py` | classFactory |
| `plugin.py` | пункт меню «Модули - Repoliner» и кнопка на панели |
| `core.py` | ядро без QGIS и Qt: чтение архивов, запись и чтение `plugins.xml`, состояние архива, совместимость. Тест `tests/test_core.py` |
| `xmlparse.py` | свой разборщик XML, перенесён из Isoliner (`landxml.py`). Отказ при объявлении сущностей |
| `view.py` | окно, дерево и действия. Логики расчёта не содержит |
| `i18n.py` | словарь RU/EN, `tr()`. Сообщения ядра не переводятся |
| `qt_compat.py` | константы Qt5/Qt6 |
| `tests/` | pytest, в выгрузочный архив не входит |

Вне пакета: `scripts/build_zip.py` (сборка), `tools/smoke_view.py`
(прогон окна на PyQt6/PyQt5 с подставным qgis, в контейнере без QGIS),
`tools/audit_archive.py` (проверка любого архива модуля перед
выкладкой: metadata, диапазон QGIS, мусор, запреты сканера каталога,
места для Qt6). Отчёт по модулям Информ++ от 17.09.2026 -
`docs/audit_2026-09-17.md`.

## Чего делать нельзя

- **Модули `xml` не берутся.** Сканер каталога plugins.qgis.org
  блокирует `xml.etree.ElementTree`, `minidom`, `pyexpat`, а `defusedxml`
  в поставке QGIS нет. Ловилось дважды в Isoliner. Разбор только через
  `xmlparse.parse`. Сторож `tests/test_scanner_rules.py`.
- **`tests/` в выгрузочный архив не кладётся**, `.pytest_cache` и
  `__pycache__` не кладутся никуда. Сканер секретов однажды заблокировал
  версию Isoliner из-за `.pytest_cache/CACHEDIR.TAG`. Сборка только
  `python scripts/build_zip.py`.
- Голый `except Exception: pass|continue` не пишется: сканер bandit
  (B110/B112) блокирует загрузку. Проверка `bandit -r repoliner -x
  repoliner/tests`.
- В `metadata.txt` нет одиночного `%`. Сторож `tests/test_metadata.py`.

## Сборка и выдача

- `python scripts/build_zip.py` даёт `dist/repoliner.zip` (рабочий, с
  тестами) и `dist/repoliner_upload.zip` (для каталога, без тестов) и
  печатает версию из каждого архива.
- В ходе работы в чат уходит только `repoliner.zip`. Коммит, пуш,
  архив для каталога и заметки к выпуску делаются один раз, когда
  Валерий скажет «релиз».
- **Версию двигает только последняя цифра.** Среднюю поднимает Валерий.
  Каждая отданная сборка получает свой номер, два разных архива под
  одним номером недопустимы. При бампе запись идёт в changelog
  `metadata.txt` первой строкой (сторож `test_version_is_first_in_changelog`).
- Приёмка на распакованном архиве: `ast.parse` каждого модуля,
  `configparser` с интерполяцией на `metadata.txt`, полный прогон
  `python -m pytest -q -p no:cacheprovider repoliner/tests`,
  `QT_QPA_PLATFORM=offscreen python tools/smoke_view.py` и `... en`.

## Проверяемая цель

Задача не поставлена, пока не назван критерий готовности, проверяемый
запуском. Для нового поведения сначала называются команда и ожидаемый
результат, потом пишется код. Для ошибки сначала тест, который её
воспроизводит и падает. «Должно работать» результатом не считается.
Если прогнать нельзя (нет QGIS в контейнере), это говорится вслух.

Живая проверка 0.1.0 (у Валерия): собрать реестр из двух архивов,
«Копировать адрес», вставить в «Модули - Управление и установка модулей -
Настройки - Добавить», увидеть оба модуля в списке и поставить один.

## Требования к текстам

Действует свод из AGENTS.md Isoliner, коротко:

- тире только ` - `, длинного тире нет, точки с запятой нет, двоеточие
  только перед списком, в соотношениях, адресах и названиях;
- предложения короткие и полные, абзац открывается тезисом;
- разговорной лексики нет, стоп-слова стережёт `tests/test_stopwords.py`;
- «количество» там, где считаются штуки;
- утверждение без сравнения и без оценки;
- заметки к выпуску пишутся для пользователя: сначала что он увидит,
  потом одной фразой почему. Имён функций и файлов в них нет;
- голос компании «мы», в деловых документах для заказчика первого лица
  нет.

## Открытые вопросы

- Совпадение имени модуля с официальным каталогом. QGIS сливает
  записи, и побеждает репозиторий, загрузившийся последним. На живом
  прогоне Isoliner 5.13.14 и Isoliner3D 1.3.1 из своего реестра были
  перекрыты 5.13.4 и 1.2.0 из каталога. С 0.1.2 окно об этом пишет.
  Устранить можно только отключением официального репозитория на
  машине.
- Метка `generator` у реестра ночных сборок Isoliner. Скрипт
  `make_nightly.py` её не ставит, поэтому Repoliner этот реестр не
  откроет. Решается в Isoliner, если понадобится.
- Раздавать веб-сервером нужно отдельную папку реестра, а не
  `Dropbox\ИИ` целиком: там лежат файлы, которые не должны уходить
  в сеть.
